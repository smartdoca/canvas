# 文字、单元格和元素的操作范围

延续既定飞书思维画布方向，参考本机 slatetsx 的流程图路径工具、表格范围选择和 Slate 文字命令。本轮集中修复持续实测发现的问题，并按照完整创作流程补查其他功能。

## 操作范围

| 当前状态 | 可见工具与行为 |
| --- | --- |
| 未选择元素 | 关闭元素样式面板及原选区工具；切换工具、删除目标或进入文字编辑时也清理对应面板 |
| 选择元素 | 根据元素能力显示操作。画笔和线条显示描边、线宽与线型；连线显示路径、端点箭头和重置；文字载体才显示整段字号、字重与文字颜色。混合多选取共同能力 |
| 选择整张表格 | 提供表格元素操作与行列控件；单元格工具不冒充元素工具 |
| 单元格光标编辑 | 实际 Slate 编辑器，支持多段输入与原生文字选择。保留行列选择、插入、调整尺寸等表格控件；不显示单元格范围框或无选区文字格式条 |
| 选择多个单元格 | 显示统一范围与批量工具：水平/垂直对齐、文字格式、字号、文字颜色、背景、合并拆分及行列操作。工具定位到选中范围，命令执行后保留范围，不展示整表连线端点 |
| 选择文字 | 仅文字格式条出现，操作应用到文字选区。折叠为光标后隐藏；操作格式按钮或链接输入时保留 Slate 选区 |

单格内拖动选择文字，跨格拖动或 Shift 选择形成矩形范围；表格接管跨格的指针移动和抬起，避免浏览器选字、原生画布拖动同时响应。卡片等文字编辑区没有输入框 outline，原生 Text 的选择矩形也不重复绘制。

## 连线、导图与点阵

- 折点拖动联动相邻线段，绑定端点维持轴向及端口进出方向约束，避免从图形内部反向接入。自动与手工路径统一正交化，反向端口使用独立引出段，合并共线/重复点，清除回折回环；连续操作不靠不断追加短段完成。未绑定端点按两端位置决定水平或垂直起步。
- 收敛误差由原先半像素缩小到数值误差级，避免相差 0.1、0.3 像素的端点被合成一条斜线。旧保存的异常手工路径也在视图载入时恢复正交，不替换元素 ID。
- 导图加号跟随当前分支的左、右、上、下方向；上方分支额外预留工具栏间距。新增后继承分支方向，保留手工位置。
- 点阵为固定 20 CSS px 间距、固定点径；平移只更新相位，缩放不改变密度。

## 所有文字载体的共同能力

普通文字、便签、卡片、流程图节点、表格单元格和导图节点使用同一 Slate 命令层。支持多段、局部粗体/斜体/下划线/删除线/代码、文字色/高亮/字号、对齐，以及以下输入快捷方式：

- `#` 至 `######` + 空格：标题；`>` + 空格：引用。
- `-` / `*` / `+` + 空格：无序列表；`1.` + 空格：编号列表。
- `[ ]` / `[x]` + 空格：待办，编辑时可切换勾选。
- 三个反引号 + Enter 或空格：代码块。
- `**粗体**`、`*斜体*`、`~~删除线~~`、行内反引号及 `[文字](URL)`。
- 列表 Enter 续项、空项 Enter 退出、Tab/Shift Tab 缩进；在表格里 Tab 保留单元格导航。
- Cmd/Ctrl K 插入或修改链接，可修改显示文字、地址或移除链接；直接输入 URL 后空格自动转链接，HTML 粘贴保留合法链接。

链接在原生画布、重开和 SVG 导出中保留。非编辑态悬停可打开；编辑时 Cmd/Ctrl 点击打开。过滤不可导航协议。原生绘制和编辑态共同渲染标题、列表前缀、引用与代码背景。

## 完整体验追加发现

1. 图片/模板插入曾使用 Leafer 初始化时的旧屏幕坐标，首次插入可能落到可视区域外。定位时刷新 client bounds，避免把布局变化误算成内容坐标。
2. 本地撤销和画布元素粘贴用资源 ID 直接构造 Image，触发无效请求。历史、受控值、元素粘贴及 API 插入均先作资源渲染投影，再通过宿主资源回调解析；对外仍返回稳定资源路径。
3. Leafer 编辑结构化文字时会临时打开父容器的子元素命中；该状态不进入持久化场景，避免仅选择/编辑焦点就产生内容更新。
4. 新建元素分配 ID、同一 ID 的手绘形状替换和命令中的短暂清空都会产生选择事件。样式面板按元素实例及稳定 ID 判断身份，避免修改样式时被意外关掉；真正清空选择则隐藏并关闭面板。
5. 编辑节点文字后，Leafer 可能仍把文字当作独立拖动目标。退出编辑回到语义元素；画布指针操作重新关闭该容器的内部命中，拖动整张卡片或导图节点，保留标签内边距。
6. 标题内手动设置字号不再叠加标题倍率；列表输入法候选关闭/保存时排除视觉前缀，避免把项目符号误写入协作文字。
7. 较长的元素工具栏曾按固定宽度定位，导图靠左时被侧栏遮挡。改为测量实际宽度、为左侧工具预留空间；窄屏随可用宽度换行，保留完整操作范围。
