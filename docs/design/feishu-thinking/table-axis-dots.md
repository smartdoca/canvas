# 表格边缘悬浮点

本轮沿用现有画布样式，按用户截图和本机 `slatetsx/src/styles.css`、`components/TableBlock.tsx` 的边界插入交互调整。行列操作独立在表格边缘，格式工具栏保持清晰。

- 上侧列边界、左侧行边界默认显示灰色小点；悬停或键盘聚焦时放大为蓝底白色加号，并显示对应插入线。
- 包含首行、首列及末尾追加入口；轨道仍可选择整行、整列并打开批量操作菜单。
- 移除对象工具栏里的添加行、添加列按钮，以及右侧、底部的整条加号按钮。
- 格式工具栏放在表格上方并预留边界控件空间，顶部不足时放到表格下方；表格移动手柄向左上避让，保证角落插入点完整可见。
- 表格键盘导航不拦截按钮上的 Enter，保证聚焦插入点可以直接激活。

这是局部界面调整，未新增动效或修改界面文案。删除了重复的图标入口；保留右键菜单、批量增删、文字样式和既有数据结构。由主 Agent 查看默认、列悬停、行聚焦及菜单截图自检，未派独立评审者、未打分。

## 验证

`yarn type-check`、`yarn lint` 均通过。以下四项浏览器用例连续运行三轮，每轮 4/4 通过：

1. 表格范围选择、富文本合并拆分、拖动列宽、插入删除与单元格身份保持。
2. 单元格富文本、对齐、合并后的 Tab 导航与只读行为。
3. 灰点默认状态、悬停加号及参考线、工具栏避让、Enter 插入、行列插入与右键批量操作。
4. 末尾悬浮点追加行列、单元格输入与检查点恢复。

另对表格移动手柄的选中、拖动和撤销用例重复运行三次，3/3 通过。
