# 深度交互与多行富文本

本轮继续深化已确认的飞书思维画布方向，重点是用户指出的拖入创建、连线、表格和文字编辑。没有重新选择视觉方向。

## 参考与实际范围

飞书参考页面本轮浏览器连接暂时不可用；沿用此前实测画面、用户补充截图，以及飞书官方[连线说明](https://www.feishu.cn/hc/zh-CN/articles/132979810163-在画板中使用连线)。表格参考本机 `slatetsx/src/components/TableBlock.tsx`、`tableCommands.ts`、`tableNavigation.ts` 的选择、行列操作和富文本模式；协作参考其 `yjs.ts` 的字符分支、稳定身份、本地与远端事务区分。未引入 slatetsx 的整个文档应用或第二条协作传输。

## 协作与数据

继续使用 `aidcanvas-yjs` schema 1；没有新增元素 tag、改变 epoch/checkpoint 身份或替换保存通道。内容文字仍是原生 Text/Y.Text，选择和手势预览不进入共享文档。

一次 native flush 中的文字、格式和内容撑高合为一个本地事务、更新与撤销项。未改变公开方法签名。关闭/卸载时即使视图 flush hook 已先移除，也会保留最后输入。单纯打开/关闭未修改的编辑器不触发自动尺寸写入。

已实测：同格离线多行输入在重连后保留双方内容；本地撤销保留对端文字；远端应用无回写；远端插行保持活动单元格 ID 与编辑器；远端删行或合并覆盖活动格时关闭编辑器，合并锚点保留其内容。双副本最终投影一致。

### 明确边界

- 当前 schema 1 校验明确禁止 Y.Text attributes。`data.richText` 仍按整字段同步，尚未实现 slatetsx 那种逐字符格式 CRDT；不同人同时改同一文本框的格式可能遵循最后写入规则。
- 表格仍是原生场景单元格结构，并未宣称所有并发插行、删除、合并冲突都等价于 slatetsx 的稳定行列命令日志。本轮验收覆盖列出的具体场景。
- 不包含通用避障路由、所有专业图形库、嵌套文档块/公式/媒体、导图选中分支复制、云分享后端或移动真机键盘验收。HTML 表格粘贴主要导入受支持的富文本内容，不承诺所有外部表格属性无损。
- 演示宿主的跨页 receipt 不是数据库持久 ACK。正式 Doca 网络、权限、持久队列与 ACK 仍由宿主负责，本轮未做服务端上线验证。

## 视觉与证据

无额外说明性 UI 文案。类型格式条去掉与当前元素不相关的按钮；全局搜索交还宿主；手机文字编辑时临时隐藏左工具条，避免遮挡格式按钮。

连线格式条定位包含绑定两端对象的范围，优先放在对象上方空白处，避免压住表格表头或便签文字。独立复核指出的遮挡与示例路径边框重合已修正，结论见 [本轮复核](deep-interactions/review.md)，本轮不打分。
