# 常见容器

沿用现有白板工具栏、蓝色选中态和轻量线性图标，按参考图提供六组、19 种容器。入口为左侧「分区 (F)」；移动端先展开更多工具。保留图标和名称，不增加重复的功能说明。

| 分组 | 类型 |
| --- | --- |
| 选区、画板 | 选区、画板、软木板 |
| 演示、打印 | 16:9、4:3、3:4、1:1、A4、演示文稿 |
| 原型画板 | Phone、Pad、Web、Watch |
| 自动布局 | 水平、垂直 |
| 泳道 | 水平泳道、垂直泳道 |
| 特殊容器 | 坐标轴、矩阵 |

点击放置、拖拽创建、从菜单拖入和跟随预览共用尺寸定义。比例画板按比例创建并锁定缩放比例，设备使用常见逻辑尺寸。演示文稿采用 16:9 画板；泳道默认三条，矩阵为四象限。

新建容器会收纳覆盖范围内的对象。对象可以拖入、移出，容器可以嵌套，整体移动保留内部坐标。水平、垂直容器自动排列内容，支持拖动排序、尺寸变化后的重排、删除补位和内容撑开。泳道、象限和坐标轴标签可以双击编辑；尺寸变化只更新现有分隔线和标签位置，保留用户文字。解除容器保留内容并移除容器自身标题及辅助图形。

数据沿用现有 Frame、Text、Rect、Path 及 data 字段，复用原有保存、撤销、协同和导出流程。未更改包的宿主接口或协同协议。

## 手机外观

Phone 容器现在带石墨色圆角机身、顶部听筒和摄像头、侧面静音/音量/电源键、底部手势条。硬件外观共用一份矢量尺寸定义，同时用于画布、跟随预览和拖拽预览；调整容器尺寸时同步更新。硬件不可单独选中，显示在内容上方，解除容器时随外壳移除。保留内容坐标、用户编辑的标题和字体大小，不增加界面说明或额外动效。

旧 Phone 容器在渲染时补齐硬件外观，直接导出旧场景也使用同一份外观定义。SVG/PNG 的导出仍在独立场景中执行，不因导出修改文档。

本次 10 个容器场景连续三轮 **10/10、10/10、10/10**，共 30 次通过（59.4 秒）。旧场景直接导出补齐后，再对手机外观与导出、保存和协同场景连续检查三轮，每轮 **3/3**。`yarn type-check`、`yarn lint` 和 `git diff --check` 通过。已自检实际画面及 200% 画面，未独立评审。

## 比例约束与工具栏下拉框

设备预设 Phone、Pad、Web、Watch 与打印、演示预设共用比例定义，跟随预览、任意方向拖拽创建及原生边角/边缘缩放均保持比例。加载旧设备容器时也恢复比例锁定，普通画板继续允许自由调整。

对象字号、线宽、文字范围字号、单元格范围字号、行样式及自定义块选择共用自定义下拉框。使用现有白底、蓝色高亮和选中对勾，支持方向键、首尾键、输入查找、Enter 选择、Esc 取消、点击外部关闭和视口边界避让。鼠标打开菜单保留编辑焦点及选区；修改字号后文字和单元格范围均保留。连续撤销/重做时跳过过期的 Slate 选区，避免读取已删除的段落。

针对比例创建、原生缩放、下拉交互、富文本字号撤销/重做、标题字号渲染及单元格范围格式化，六个场景连续三轮 **6/6、6/6、6/6**，共 18 次通过（45.5 秒）。验证使用关闭热更新的独立预览，避免工作区同时编辑导致页面重载。`yarn type-check`、`yarn lint`、`git diff --check` 通过。已自检 100% 和 200% 实际画面，未独立评审；复用菜单展开和选项高亮反馈，没有增加界面说明。
