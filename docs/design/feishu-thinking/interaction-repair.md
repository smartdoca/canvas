# 点选、放置、单元格与分支方向修复

延续既定飞书画布方向，本轮处理用户继续实测提出的缺陷，未重新设计页面或修改宿主搜索归属。实现参考本机 slatetsx 的 `components/DiagramBlock.tsx`（路径点击包络、端点/折点/分段工具）与 `components/TableBlock.tsx`（文字光标与单元格范围的切换）。

## 缺陷与结果

| 用户反馈 | 原因与修复 |
| --- | --- |
| 模板连线不能点选，普通线可操作点少 | 模板线此前属于不可命中的派生元素，普通路径仅有一个中段柄。现在用统一的屏幕坐标路径命中，点击线周围约 18 CSS px 的区域可选择；缩放不缩小可点击宽度。模板线也支持端点、折点和分段操作，模板局部坐标正确转换到画布坐标 |
| 选元素后鼠标没有带着元素 | 图形、便签、文字、表格、分区、导图和表情激活后，鼠标进入画布即显示对应尺寸的半透明预览。预览不进入场景、保存或撤销；点击落位，Esc 取消。分区支持点击默认尺寸和拖画 |
| 表格富文本基本不可用 | 原生 TextEditor 的 `white-space: normal` 和 flex 布局覆盖 Slate，真实逐键输入会发生空格错位。恢复 Slate 需要的 `pre-wrap` 与块布局，保留原生位置/缩放适配、文字样式和垂直对齐。活动格仍为实际 `withReact`/`withHistory` Slate，而非 textarea |
| 文字编辑后出现“创建相连图形”卡片 | 连线菜单未随编辑器和选区生命周期清理。现在进入文字编辑、切换选区或点击外部时关闭；取消手势也不遗留菜单或新线 |
| 折线越操作越碎 | 手势结束时合并零长度/共线段，移除回折形成的回环；绑定端点附近的分段拖动复用已有折弯，不反复插入短折段。保留手动路径与绑定端点，提供“重置连线路径”；Alt 拖动线段可插入折点，双击折点删除 |
| 单元格内外两层蓝框 | 除 DOM outline 外，原生 selector 的 Stroker 还会在布局更新时重新显示。现在清空其绘制目标，同时关闭单元格编辑框；根据用户最新要求，单击格内直接显示文字光标，格内拖选文字，跨格/Shift/行列选择才显示范围。空格也可单击进入编辑 |
| 拖动导图分支后加子节点回到右侧 | 旧布局只使用整图方向。现在显式拖动保存该节点相对父节点的位置及分支方向；子节点继承最近的分支方向，支持左/右/上/下。新增子节点、多行文字、保存重开保持方向。用户主动选择整图布局时清除分支手工布局并重新排列 |

## 验证方式

新增 `tests/browser/interaction-repair.spec.mjs` 的 9 个场景使用真实指针与逐键输入，覆盖单击空白格后输入含空格的文字、Enter 多段、格式按钮后续输入、文字拖选/跨格范围、模板路径多位置点选、不同缩放下的点击区域、只读、预览/取消/落位、连线菜单关闭、连续 12 次分段编辑不增加冗余点、路径重置/撤销，以及拖到左侧与上方后继续添加多行子节点并重开。

最终重复回归与静置结果记入 [验收记录](verification.md)。首次复现的 3 个故障用例确实失败，修复后重新检查；此前使用整体 `insertText` 的测试不足以暴露逐键空格错位，本轮改用真实键入补充覆盖。

## 数据与边界

继续使用原生 Leafer 场景和 schema 1。手动路径的 `data.vertices`、分支的 `data.mindDirection` / `data.mindOffset` 使用现有 JSON data 槽，未新增元素 tag、保存通道或公共方法。选区、命中包络、预览及菜单只存在于视图。旧模板保留自身 ID 和类型，不做整图替换。

本轮路径收敛用于清理手工编辑的冗余段，并非通用障碍物避让。逐字符格式 CRDT、所有并发表格结构冲突和正式宿主服务端 ACK 的既有边界仍见 [深度交互说明](deep-interactions.md)。
