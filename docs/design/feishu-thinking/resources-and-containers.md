# 富文本容器、资源与连线交互

2026-10-17，当前工作区源码。

## 操作约定

- 表格单元格、卡片和便笺共用 `CanvasSlateEditor`。卡片、单元格单击内容放置光标；便笺第一次点击选择对象，已选中时再点一下才放置光标，拖动保持对象模式。流程图、导图和连线标签保留单击选中拖动、双击编辑普通文字。跨单元格拖动产生矩形选区，同一单元格内拖动选择文字。
- 新建便笺、卡片和单元格文字默认顶部对齐。卡片和表格内容水平换行、垂直滚动；便笺随内容自动增高，拖动可增加留白，不能缩到文字/图片内容高度以下。删除内容保留手动留白。便笺提供 12 套配色、描边、圆角及虚线预设。
- 左上小手负责选择整个容器及拖动位置；便笺的对象模式也可直接拖动正文区域，卡片/表格正文区域负责文字光标。文字格式条仅在文字范围选中时出现；对象条、单元格范围条、文字条的作用域互斥。文字条在小手之上，避免遮挡格式按钮。
- 选择创建工具后，元素预览跟随指针，点击画布完成放置。保留现代图形、导图、文本、便笺、表格、框选区域、图片、文件、画笔、橡皮及宿主扩展；旧原生基本形状菜单和 roughjs 渲染/控制已移除。
- 连线保留宽命中区、端点绑定和正交路线。拖动线段或顶点进入 7 屏幕像素范围时显示轴线提示；释放提交规范化路线，合并重复、共线点及闭环。预览期间不写模型，Escape 取消；端口方向约束仍生效。
- 撤销/重做保留当前平移、缩放。公共新增、修改元素命令独立提交，避免新建与紧随其后的移动混入同一步；媒体结构操作独立于普通文字输入提交。

## 宿主资源接口

`CanvasEditorResources` 增加 `uploadAttachment`，与 `uploadImage` 共用文件名、来源、AbortSignal 和进度上下文。返回稳定 `path` 及 name/size/mimeType/dimensions。新增 `CanvasResource` 与 `onResourcePreview(resource)`，SDK 交给宿主处理预览；宿主仍负责存储、地址解析、下载授权和权限复核。句柄新增 `insertAttachmentFile`；`insertImageFile` 保留。

卡片/单元格支持文件选择、粘贴、拖入。画布支持文件选择、粘贴、拖入；画布图片和附件以及带 `canvasExtension` 标识的宿主元素均可绑定连线。上传队列保持文件顺序，失败后可重试或取消，保持原始插入范围/画布位置。切换只读、目标删除、关闭编辑器、切换模型或卸载后不能晚到插入。

Rich media 是 Slate 真正的 void block，包含必须的空 text 子节点。编辑时先选择原子节点，再通过下一次点击或预览按钮调用宿主；只读原生视图直接转交预览。复制粘贴完整资源元数据并生成新的节点 id，资源 path 保持稳定。文档不保存 Blob、临时 URL 或上传状态。

示例 `/` 使用 IndexedDB 模拟宿主存储并提供预览层；`/examples/doca/` 使用隔离的宿主回调/传输测试夹具。这些示例不是生产 Doca 服务的接入证明。

## 数据与导出边界

保持 `aidcanvas-yjs` schema 1。native `Text.text` 以 U+FFFC 表示媒体，段落用换行分隔；`data.richText` 仍为 version 1，资源字段位于 paragraph 上。文字 CRDT 与整个 richText 属性 LWW 沿用现有协议，没有逐字符格式 CRDT、第二传输、数据库变更、自动迁移或历史数据回填。

滚动位置、图片解析结果、拖动预览、上传状态只存在视图。SVG/PNG 导出嵌入经宿主 `readImage` 授权读取的行内图片；附件导出可读文件名。容器按自身尺寸裁剪，导出从内容顶部开始，不序列化临时滚动位置。原生画布图片沿用已有资源协议。

## 收尾前的验收记录

以下为范围细化前的历史结果；最新操作范围、对齐弹层、便笺高度和完整回归见 [最终交互验收](interaction-polish.md)。

测试在隔离页面/模型上执行，未操作用户文档。最终行为源码的验收结果：

- 87 个交互场景连续三轮，共 **261 次通过**。富文本/容器/资源及深度交互分组 87 次（78.33 秒）；导图、连线、选择、创建、Markdown、工具栏、图片编辑、撤销、移动端等分组 174 次（247.66 秒）。
- 宿主接入、协作、对齐与文字编辑补充检查 **29 项通过**（84.90 秒），包括双页面、断线重连、原子复制、只读与 60 秒空闲无写入。
- PNG/JPEG/WebP/SVG、资源权限、取消、独立 SVG/PNG 重开、纯导出与限制检查 **9 项通过**（7.71 秒，含命令启动）。两个性能检查与思维画布 60 秒空闲检查通过；10000 元素导出保持只读。
- 当前模型源码通过 Vite SSR 载入执行 **27 项模型测试**；未用旧 dist 充当当前源码结果。
- 最终 lint + TypeScript 连续三次通过；宿主 TypeScript 示例检查通过；`git diff --check` 通过。

首轮测试发现并修复了快速切换单元格时复用旧范围的问题；跨行文字拖选测试改为拖动滚动区内实际可见的行。上述最终分组均在修复后重新执行。旧手绘导出测试已按移除 roughjs 的授权替换为原生描边、填充与确定性导出；真实文件、权限、无写入等覆盖保留。
