# 思维画布：交互与对齐验收

2026-10-17，当前 AidCanvas 工作区源码，隔离测试数据。

## 最终操作范围

| 对象 | 点击与编辑 | 尺寸与内容 |
| --- | --- | --- |
| 便签 / 标签 | 第一次点击选中、显示对象工具栏；可直接拖动正文区域。已选中后再次点击进入 Slate 富文本；拖动不会进入编辑。 | 默认顶部对齐，水平换行。文字、字号及行内图片决定最小高度；内容增多自动撑高，可手动加高，不能拖到内容以下。删除内容保留额外留白。 |
| 卡片 | 正文单击直接进入共享的 Slate 编辑器，小手选择 / 拖动容器。 | 默认顶部对齐，水平换行、垂直滚动。 |
| 表格 | 同格放光标 / 拖选文字，跨格拖出矩形单元格选区。小手选择 / 拖动整表。 | 单元格默认顶部对齐，支持多行 Slate 富文本；行高由用户调整，溢出在格内滚动。 |
| 流程图、导图、连线标签 | 保留单击选中拖动、双击修改普通文字。 | 对象本身的工具栏管理其整体文字、外观和连接。 |

便签提供 12 套预设：经典黄、蜜桃橙、玫瑰粉、薄荷绿、晴空蓝、薰衣草、象牙纸、深空灰、极简描边、柔和圆角、灵感虚线、重点蓝。创建预览与最终便签的样式一致；已有便签可直接应用，保留文字和局部格式。

## 对齐与工具栏

按用户提供的截图，将原生下拉框和分散按钮替换为一个“文本对齐”图标。弹层上排为左、居中、右、两端对齐，下排为顶部、垂直居中、底部对齐；浅紫底与紫色图标分别显示两组当前选项。选择后可继续设置另一组。窄屏弹层会向视口内避让。

便签、卡片、整表和单元格选区复用同一个控件。单元格多选时对整个范围应用；混合状态不误显示一个统一值。对象水平对齐会更新所有段落的对齐并保留文字格式。两端对齐对实际换行行分配字间距，末行保留自然宽度；Slate 和原生 / SVG 渲染均支持。

文字选区仍有独立格式条：只在选中文字时出现；仅管理选中段落的水平对齐和文字格式。光标编辑时不显示格式条。对象模式、单元格范围模式和文字范围模式保持各自的作用域。退出编辑点击空白会清空选择，并清除上一击的原生双击等待，避免新建意外文字或立即重进编辑。

## 前述七项需求

| 需求 | 实现与验收入口 |
| --- | --- |
| 拖选多个单元格并合并 | 从活动光标跨格拖动、反向拖动、Shift 扩选、合并 / 拆分、行列操作及选区格式；保留稳定单元格 ID。 |
| 卡片 / 表格共享多行富文本 | 复用 `CanvasSlateEditor`，支持局部格式、Markdown、链接、换行和有边界的滚动。便签在此基础上增加内容最小高度。 |
| 图片与附件 | 富内容和画布均支持选择文件、粘贴和拖入。上传队列保持顺序；失败可重试 / 取消，保留原插入位置，关闭或只读阻止晚到插入。 |
| 宿主资源管理与预览 | `resources.uploadImage/uploadAttachment/resolveUrl/resolveDownloadUrl/readImage`；`onResourcePreview` 交回宿主。文档仅保存稳定 path 和元数据，不保存 Blob / 临时 URL。 |
| 媒体连线、自定义元素、旧工具移除 | 画布图片、附件及带扩展标识的宿主对象均有连接点。旧重复基本形状菜单和 roughjs 依赖已移除；现代图形、自定义元素与自由画笔保留。 |
| 撤销位置跳变 | 撤销 / 重做保留当前缩放平移；创建、属性修改和媒体结构操作分开提交。便签创建也立即成为独立操作。 |
| 折线操作点收敛 | 拖动进入 7 屏幕像素范围显示轴线提示；释放后规范化路线，合并重复 / 共线点及闭环，保留端口方向约束。预览不写模型，Escape 可取消。 |

横向滚轮事件在整个画布范围内拦截浏览器导航；指针进入画布时对祖先滚动链临时设置水平边界，离开、失焦及卸载后恢复原样。富文本纵向滚动不会同时平移画布。验证覆盖原生 wheel、Shift 横滑、修饰键缩放、只读与宿主外部滚动；物理触控板的系统级历史手势未由自动化模拟。

## 数据与宿主边界

沿用 `aidcanvas-yjs` schema 1 与 `richText` version 1。文本仍使用字符 CRDT，格式 / 资源元数据沿用整体属性 LWW；没有新增传输、数据库迁移或历史文档回填。便签最小高度约束、滚动位置、预览图缓存和上传队列是视图状态；用户编辑产生的容器尺寸走现有模型事务。

当前演示地址为 `http://127.0.0.1:4179/`。上传 / 预览由演示宿主和隔离宿主夹具实现，不能据此声称生产 Doca 资产服务、持久服务端 ACK 或发布包已完成接入。未执行生产构建、发布、提交或部署。
