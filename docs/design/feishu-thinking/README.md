# 飞书风格思维画布

## 方向与参考

用户要求将现有画板升级为思维画布，UI、交互和细节以已登录的飞书画板为参考；不再沿用上一版 tldraw 底部工具条布局。本次实际打开并检查了参考画板、图形库、快捷键抽屉与模板入口，没有修改远端文档内容。

参考视口为 1728×837：白色画布、左侧 52px 工具条、顶部两组 44px 悬浮操作区、右下分组导航、右侧模板引导。图形库为左侧 260px 抽屉；大纲和帮助为右侧 300px 抽屉。图标由项目自己的 SVG 图形构成。导出替代本地产品没有的云分享操作。

原生导图与连线行为还参考了飞书官方说明：[思维导图](https://www.feishu.cn/hc/zh-CN/articles/728977871585-在画板中插入思维导图)、[连线](https://www.feishu.cn/hc/zh-CN/articles/132979810163-在画板中使用连线)。富文本参考本机 `slatetsx` 的 Slate 选区、marks 和单元格编辑处理，采用相同版本的 Slate 核心，未引入其整套文档应用和流程图依赖。

## 已实现

| 能力 | 实际行为 |
| --- | --- |
| 思维导图 | 原生节点、稳定关系 ID；Tab 子主题、Enter 同级、Shift+Tab 父主题；折叠、四种布局、四种主题、分支移动、整图复制、大纲定位 |
| 图形与连线 | 常用流程图形、四边连接点、端点吸附/重绑、折线/直线/曲线、中段调整、移动后跟随、连接文字、快捷创建相连图形、拖入创建 |
| 模板 | 时间线、组织架构、系统架构、思维导图、增长飞轮、金字塔、移动线框、复盘；搜索分类、悬停预览、方向键选择；插入后均为可编辑原生对象 |
| 表格 | 点字定位、文字/跨格选区、行列选择和边界原位插入、批量增删、合并拆分、行高列宽拖动、多行 Slate 富文本、范围格式/对齐、Tab 导航与增长、富文本/TSV 粘贴 |
| 富文本 | 独立文字、便笺、卡片、节点和单元格共用多行 Slate 编辑层；局部粗体、斜体、下划线、删除线、行内代码、字号、颜色、高亮、段落对齐、清除格式；支持清理后的 HTML 粘贴及内容撑高 |
| 查找与导出 | 保留宿主 find/replace/reveal API；画布不提供全局搜索按钮、面板或快捷键拦截；富文本绘制和 SVG/PNG 导出保留受支持的样式；JSON 保存结构化数据 |
| 导航与响应式 | 缩放、适配、平移、网格、缩略图；手机低频工具折叠、菜单/帮助入口保留；插入适配避开左工具栏；对象格式条折行后重新定位 |

中文输入保留候选阶段的本地 DOM；远端字符更新不覆盖候选。确认后按字符 CRDT 合并。协作编辑中的撤销使用模型的本地事务历史，文字与格式在一次 text-session 提交中写入，避免一次输入需要撤销两次。

## 数据与集成

- 沿用 `aidcanvas-yjs`、schema 1、epoch、checkpoint 和 ACK 契约。没有增加新的元素 tag。
- 导图层级、表格语义、连接关系与富文本 payload 保存在 schema 允许的 `data` 下。文字本体仍是原生 Text / Y.Text，可供现有查找、替换和宿主服务使用。
- `CanvasTextSession.commit` 增加可选 formatting 参数，旧的一参数调用保持兼容；文字和格式可在同一个 Yjs 事务中提交。
- 选择、缩放、抽屉状态和编辑器光标保持为视图状态。原生临时 `textEditing` 字段在持久化投影中剔除。
- 资源上传、权限、云分享、评论服务和持久 ACK 仍由宿主提供。现有评论锚点、只读、资源回调和稳定 editor handle 保留。

## 范围边界

这次是思维画布核心升级，尚不能宣称飞书所有功能完全等价：没有完整 UML/专业图形素材库、完整文档块编辑或云端分享后端。选中导图分支复制时当前复制整图。搜索折叠节点不会自动展开隐藏分支。

这轮操作细节、实际证据和协作边界见 [深度交互验收](deep-interactions.md)。

后续实测反馈的路径点击/折点收敛、鼠标随行预览、单元格文字选择和导图分支方向修复见 [交互缺陷修复](interaction-repair.md)。

字符内容按 Y.Text 合并；`data.richText` 样式 payload 按字段同步。同一文本框多人同时修改不同格式时遵循字段冲突规则，尚未实现逐字符格式 CRDT。图片的 `.canvas` 文件仍保存稳定资源引用；独立 Demo 的图片 Blob 存放在浏览器 IndexedDB，跨浏览器迁移需要宿主资源服务。
