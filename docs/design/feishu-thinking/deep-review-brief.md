# 本轮界面约束与验收范围

用户要求以飞书思维画布的创建、连线手感为参考，表格选择、文字/单元格操作、行列增删参考本机 slatetsx。便签、卡片/图形、导图节点和单元格都需要多行富文本。搜索入口与搜索界面由宿主实现，编辑器不提供全局搜索按钮。

延续现有白底无限画布、左侧 52px 工具条、上方浮动宿主/文档操作、右下导航。强调色 #3370ff，正文 #1f2329，次要文字 #646a73，边框 #dee0e3。Arial/PingFang SC，紧凑的 30px 格式按钮、6–8px 浮层圆角。无需新配色、插画或营销文案。

重点检查：连接点和端点是否清楚、格式浮层是否遮挡内容、单元格与范围选中是否可辨、行列插入/批量操作菜单是否完整可读、多行内容是否重叠或裁切、手机编辑时工具条是否超出视口。手机编辑时左工具条临时隐藏，为多行格式条留出空间。

截图桌面视口 1280×720，手机 390×844；录屏为 1440×900。截图最上方“同账号打开第二页面 / 切换只读 / 模拟断线”等属于隔离测试宿主，忽略它的布局。表格超出手机视口属于无限画布可平移内容；格式条和菜单必须可见。

只评审当前截图和三组录屏/三帧。不能从截图断言协作正确、手感完全等同参考或所有功能完成。
