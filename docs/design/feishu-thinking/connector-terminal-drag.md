# 端点附近的线段拖拽与旧模板路径

对应 2026-10-17 截图中两处方形手柄拖不动，以及右下方原生连线接入方向错误的问题。延续既有原生 Leafer 场景与端口绑定，不更改 schema 或宿主 API。

## 原因与修复

1. 绑定端点的首末线段曾沿自身方向计算位移，横拖竖段、纵拖横段时没有响应。现在统一沿线段法线移动；保留端点位置与端口朝向，通过短引出段连接移动后的线身。再次操作复用现有路径，邻近端口的折段受最小引出距离约束。
2. 拖拽中的方形手柄跟随预览路径；端口约束触发时仍停留在线上。光标提示实际的左右或上下移动方向。只有真实路径变化才提交内容与历史，沿线方向的无效拖动不产生更新。
3. 旧模板实际使用右出、左入端口，但部分数据没有显式锚点，几何算法会仅按两端距离决定起止方向。现在几何计算统一兼容旧模板的端口约定，新模板显式保存端口。
4. 原生绘制曾继续使用保存的旧 `path`，选中高亮却根据路由数据重新计算。载入、首次 API 插入及独立导出统一重建派生路径；重开旧文档时不修改持久化场景，也不因选择产生协作更新。

## 验证重点

`connector-drag.spec.mjs` 新增横向/纵向首末段的实际指针拖动，以及旧模板重开场景。检查预览和手柄真实位移、抬起前零写入、提交一次更新、绑定端点不变、连续操作不增长冗余折点、取消和撤销、原生绘制/高亮/SVG 一致，以及节点移动后的重新路由。

旧的连续拖动用例只验证端点和点数，没有断言线段实际移动，因而漏过沿线方向空拖动。现已改为对中间竖段横向拖动，并明确要求每次路径发生变化。旧路径兼容用例通过模型直接注入历史数据，避免新增 API 的路径修复提前清洗测试输入。
