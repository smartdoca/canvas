# 便签、富文本行控件和协作

用户任务：在便签和表格内编辑多段富文本，按行设置标题、列表、待办和对齐；在选区结束后使用文字工具；把资源移到画布，并看到协作者的位置。

按用户最新要求，行悬浮控件和选区工具栏直接沿用 Doca / slatetsx 的 BlockHandle、FloatingToolbar 视觉：28 × 27 的透明六点柄，220 宽的文字属性菜单，32 × 28 的标题、列表、对齐网格；文字工具采用同一套 Lucide 路径、30 像素按钮、9 像素圆角、白色面板和蓝色选中态。保留画布原有的两端对齐、代码块和自定义富文本扩展入口。字号选择复用画布的可键盘操作 Dropdown，并用相同尺寸呈现。按 Escape 或点击外部完成编辑。

关键状态：指针、键盘正在扩展选区时隐藏工具栏，结束后在选中文字上方显示；行菜单只修改悬浮目标行，远端替换该行时关闭；颜色面板与链接输入保留选区，窄屏进行边界避让。

验收重点：真实浏览器截图比对 Doca 参考源码；行操作范围、标题、待办、对齐和字体尺寸，鼠标与键盘选区结束时机，链接表单，调色板和窄屏；同一宿主双页协作和资源移动、撤销。

协作仍使用现有 schema 1：正文以 Y.Text 字符合并，格式和资源元数据继续字段级合并。富文本扩展当前为原子块，未注册类型保留数据并显示 label。浏览器验证使用本次源码和本地示例，不表示已经验证 Doca 后端或发布了 SDK。

## 列表、待办和空白行入口（2026-10-17）

参考本机 slatetsx 的 `editor.ts`、`ElementRenderer.tsx`、`BlockHandle.tsx` 和 `styles.css`：列表采用蓝色标记，随缩进切换实心、空心和方形项目符号；有序列表按层级使用数字、小写和大写字母，保留自定义起始编号，中间插项后更新后续编号。默认 16px 字号对应 22px 缩进、18px 标记和 9px 间距，随画布字号与缩放同步变化。空列表回车逐级退缩进，顶层退出列表；行首退格先移除列表再减少缩进。

待办使用可点击和键盘操作的 checkbox，完成后显示蓝底白勾、灰色文字和删除线。编辑态、原生画板绘制、SVG 和 PNG 导出使用相同几何规则。原生画板状态也可直接勾选，支持撤销和只读禁用。

空白行显示「+」，有内容时显示六点操作柄。「+」菜单提供图片和附件选择器，接入现有宿主上传、失败重试和取消流程。文件选择及上传保留目标行的实时选区；附件入口可把图片作为文件插入。单元格内的文字光标滚入可见区域，选中资源时保留资源操作位置。中英文入口文案存放在子包字典中。
