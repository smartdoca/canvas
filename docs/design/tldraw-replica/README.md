# tldraw 风格画布改版

用户目标：深度参考 tldraw 的功能与样式。在现有 React / LeaferJS 编辑器中完成可运行的界面和核心交互，保留 AidCanvas 品牌、宿主权限及资源回调。

参考：[tldraw 在线白板](https://www.tldraw.com/)，2026-10-16 实际查看。界面是全屏无限白板，主操作是直接绘制和编辑画布对象。采用浅灰画布、边缘悬浮控件、底部绘图工具栏、右上紧凑样式面板。没有新增页面级导航或装饰内容。

## 已实现

- 画布占满编辑器，不再为顶部标题栏和工具栏预留空白。
- 底部选择、平移、画笔、橡皮、箭头、文本、便笺、图片、矩形工具；上方独立撤销、重做、删除、复制与操作菜单。
- 更多工具保持挂载，收起菜单后仍可绘图；活动的隐藏工具会高亮“更多”入口。
- 右上常驻 12 色、透明度、填充、手绘/虚线/点线/实线和四档粗细。原有完整参数及扩展属性保存在“更多样式”中。
- 可直接编辑文字的便笺，支持历史记录与刷新恢复。
- 主菜单、右键菜单、编组、图层顺序、适合画布/选区、随视口平移缩放的网格，以及快捷键帮助。
- 演示页接通图片导入、IndexedDB 图片持久化、PNG/SVG 导出，以及原生可编辑画布文件的导入导出。图片资源继续使用宿主资源契约。
- 本地存储写入失败时显示保存失败，保留当前绘图并可显式重试。
- 中英文目录同步更新；只读模式保留导航，隐藏编辑控件与编辑菜单项。

手机端将文本、便笺和图片收进更多工具，常用工具点击区域为 44×44px（390px 视口）；展开的工具提供可见名称，颜色和样式控件也相应增大。保留 320px 宽度下的紧凑退让。

## 视觉评审与减法

独立评审初评 **8/10**。评审者仅读取实际截图、200% 细节和动效证据，未读取源码或制作过程。主要意见及修正：

1. 手机主工具过密：从十个入口缩为七个，扩大点击区域；次级工具收进弹层。
2. “更多样式”字小且偏浅：提升至 12px 并加深颜色。
3. 圆形/椭圆入口接近：手机工具弹层增加中文名称，保留桌面提示。

复核最终桌面与手机截图：控件无重叠、无裁切；手机菜单打开时覆盖画布，正常关闭后恢复。尚未在真实触控硬件上验证，也没有对修正结果重新打分。

减法：把顶部“保存/导入”的常驻文案收进主菜单；快速样式区用颜色与图标表达，完整参数标签只在展开时出现。没有删掉操作名称、保存状态或异常反馈。

## 范围与剩余差距

本次完成核心白板界面与常用操作，未实现 tldraw 全量功能：多页面、智能箭头绑定、小地图、云端分享和 tldraw 文件格式互通均未覆盖。原有宿主协作模型继续沿用。

独立演示页的图片保存在当前浏览器的 IndexedDB。可编辑 `.canvas` 文件保存资源引用，含图片的文件暂不提供跨浏览器资源打包；PNG/SVG 导出会包含实际图片。保存文件是 AidCanvas 原生格式。
