# 画布能力路线

0.2.0 的新增协同能力与限制见 [COLLABORATION](COLLABORATION.md)，实际验收见 [TEST_RESULTS](TEST_RESULTS.md)。以下单机本地持久化在宿主管理模式中禁用。

## 当前版本：编辑闭环

- 基础矢量和文本工具
- 直线、箭头、多边形、星形和橡皮擦
- 画布内浮动工具栏与左侧属性面板
- 图片元素
- 图片原始比例复位、比例锁定、自由变形，以及独立弹窗中的裁剪、翻转、90° 旋转和基础滤镜
- Frame 子画布：拖拽创建、选区包裹、内容裁剪
- 选中元素下方的复制、创建/取消 Frame 和删除快捷操作
- 连续自由绘制、视口中心缩放、指针锚点滚轮缩放与手型平移
- 多选编组/解组与 ⌘G / ⇧⌘G 快捷键
- 属性面板图层顺序：置顶、上移一层、下移一层、置底
- Rough.js 手绘风格切换，使用固定 seed 保持刷新和导出一致
- 属性与图层面板
- 本地持久化
- 撤销重做
- JSON、PNG、SVG 导入导出

## 下一阶段：专业编辑

- 计划实现（尚未支持）：独立 rich-text 数据模型、行内 marks、HTML 白名单、DOM 选区映射与 HTMLText 渲染适配。目前仅普通 Text 的 Y.Text 字符协同。

1. 图层拖拽排序、置顶/置底、重命名和右键菜单。
2. 锁定比例、精确位置与尺寸输入。
3. 对齐、等距分布、智能参考线与网格吸附。
4. 缩放预设与小地图。
5. 剪贴板复制粘贴、系统图片粘贴、框选增强。
6. Frame 命名、嵌套导航、活动 Frame 内创建与按 Frame 导出。
7. 菱形、箭头端点样式、文本与图形绑定、连接线吸附。
8. IndexedDB 素材存储、缩略图和大图懒加载。

## 后续阶段：生产力

1. 模板、组件和可复用样式。
2. 贝塞尔钢笔、路径节点编辑、多点折线和布尔运算。
3. 图片自由裁剪交互框、平移缩放、任意路径蒙版、标注绘制、阴影和高级滤镜。
4. 版本快照、差异预览和恢复。
5. 可选的远端文档适配器；核心编辑器不得直接依赖具体后端。
6. 元素链接、素材库、模板、演示/激光笔模式和无障碍增强。

## 暂不纳入核心

- 账号和权限；
- 管理后台；
- AI 聊天；
- 实时多人协作。

这些能力如需恢复，应作为独立适配层或独立应用接入，不能重新侵入画布内核。
